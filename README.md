# Блог Мосметро

Тестовое задание: мини-платформа с регистрацией пользователей, профилями
и публикациями. Проект реализован на Django без Django REST Framework.

## Реализовано

- регистрация, вход, выход, смена и восстановление пароля средствами Django;
- профили пользователей с биографией и загрузкой аватара;
- создание, просмотр, редактирование и удаление постов;
- разграничение прав: изменять и удалять пост может только его автор;
- пагинация ленты и страниц профилей по 10 публикаций;
- валидация уникальности email, даты рождения, размера изображений,
  длины биографии и текста поста;
- отображение загруженных медиафайлов в режиме разработки;
- приветственное письмо после регистрации: в режиме разработки письма
  сохраняются в `blog/sent_emails/`;
- для восстановления пароля на указанную почту отправляется сообщение с
  одноразовой ссылкой на смену пароля
- тесты на встроенном `unittest` Django.

## Подготовка проекта

Выполните команды из корня репозитория.

```bash
python -m venv env
source env/Scripts/activate
pip install -r requirements.txt
```

## Запуск

Выполните команды из корня репозитория.

```bash
cd blog
python manage.py migrate
python manage.py runserver
```

После запуска приложение доступно по адресу <http://127.0.0.1:8000/>.

## Тестирование и проверки

```bash
cd blog
python manage.py test
python manage.py check
python manage.py makemigrations --check --dry-run
```

Для проверки форматирования и базовых ошибок также доступен Ruff:

```bash
cd blog
ruff check .
```
